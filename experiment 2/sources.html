Data Sources & Stakeholders

Forecast / Alert Workflow

  1. Collect raw temperature data from AWS sensors and satellite feeds.
  2. Validate and clean data against the IMD database.
  3. Run heatwave prediction models to classify severity (HW / SHW).
  4. Generate and publish the alert bulletin.
  5. Notify subscribed citizens and disaster-management officers.

Data Sources

  • AWS (Automatic Weather Station) sensor network
  • IMD (India Meteorological Department) database
  • Regional satellite feeds

Stakeholders & Actions

  • Meteorologists
    • Review raw sensor data
    • Calibrate forecast models
    • Approve alert bulletins
  • Disaster-Management Officers
    • Coordinate emergency response
    • Issue public advisories
    • Track helpline calls
  • Citizens
    • Subscribe to alerts
    • Follow advisory guidance
    • Report local conditions
