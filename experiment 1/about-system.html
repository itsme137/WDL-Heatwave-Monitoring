About the Heatwave Intelligence System

Home | Alert | About | Sources | Navigation | Hotspot Map | Forecast | Subscribe | Media

Objective

To monitor, predict and warn about heatwaves so that lives can be saved and losses reduced. Temperature in °C is tracked every hour.

Data Sources

Data comes from AWS sensors, the IMD database and satellite feeds, combined using manual logs automated pipelines.

Stakeholders

Meteorologists, disaster-management officers and citizens all use the portal, each with different needs.

"Early warning is our strongest defence against heat. Act on the alert, not after the damage."
