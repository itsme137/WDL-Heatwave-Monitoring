Forecast / Alert Workflow

  1. Collect temperature data from sensors and satellites
  2. Validate and clean the data
  3. Run the heatwave prediction model
  4. Classify severity level
  5. Issue alert bulletin
  6. Notify subscribed citizens

Data Sources

  • AWS sensors
  • IMD database
  • Satellite feeds

Stakeholders and Actions

  • Meteorologists
    • Analyse temperature data
    • Publish forecasts
  • Disaster-Management Officers
    • Issue and escalate alerts
    • Coordinate relief and cooling centres
  • Citizens
    • View alerts and advisories
    • Subscribe for notifications
